# Churn MLOps Pipeline

An end-to-end MLOps pipeline for predicting customer churn in the telecom
sector using the Telco Customer Churn dataset. The project covers data
ingestion and validation, data versioning with DVC, experiment tracking
and model registry with MLflow on DagsHub, and a reproducible training
pipeline defined in `dvc.yaml`.

**Models:** Logistic Regression (baseline) and Random Forest (main model),
evaluated with F1-score and ROC-AUC.
